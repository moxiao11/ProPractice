# C++ 分文件编写程序教程

## 一、为什么要分文件编写
在C++开发中，当项目代码量增大时，把所有代码写在一个`.cpp`文件里会出现以下问题：
- 代码可读性差、维护困难，修改功能需要在大文件中定位
- 重复编译：修改一处代码需要重新编译整个文件，效率极低
- 无法实现代码复用：其他项目难以直接引用已写好的功能

分文件编写的核心优势：
 **解耦代码**：将「声明」和「实现」分离，结构清晰
 **高效编译**：仅修改的文件需要重新编译，大幅提升开发效率
 **代码复用**：头文件可被多个源文件引用，实现功能复用
 **便于团队协作**：多人可同时开发不同模块，互不干扰

---

## 二、分文件编写的核心规则
### 1. 头文件（`.h` / `.hpp`）：只写「声明」，不写「实现」
头文件的作用是**对外暴露接口**，告诉编译器「有哪些函数/类可以用」，包含内容：
- 函数声明、类的声明
- 宏定义、全局变量声明（加`extern`）
- 模板声明、类型别名（`typedef`/`using`）
- 头文件保护（必须加，避免重复包含）

### 2. 源文件（`.cpp`）：只写「实现」，对应头文件的声明
源文件的作用是**实现头文件中声明的功能**，包含内容：
- 头文件中声明的函数、类成员的具体实现
- 仅本文件使用的全局变量、辅助函数（加`static`限制作用域）
- 必须`#include`对应的头文件，确保声明和实现一致

### 3. 主函数文件（`main.cpp`）：程序入口，调用其他模块
- 包含`main()`函数，是程序的入口
- `#include`需要用到的头文件，调用其他模块的功能
- 不写具体业务实现，仅做流程控制

### 4. 头文件保护（必加！）
为了避免头文件被重复包含导致编译错误，必须在头文件开头和结尾加保护：
```cpp
// 写法1：#ifndef / #define / #endif（兼容性最好）
#ifndef _MYCLASS_H_  // 自定义宏名，建议用「文件名大写+下划线」
#define _MYCLASS_H_

// 头文件内容（声明）:类、函数声明等写在这里
#endif //结尾必须加#endif，和#ifndef对应

// 写法2：#pragma once（VS Code/GCC/Clang都支持，写法更简洁）
#pragma once
// 头文件内容（声明）
```

## 三、完整示例：实现一个“计算器”类
下面以一个简单的计算器为例，演示如何分文件编写 C++ 程序。

### 3.1 项目结构
最终我们会创建 3 个文件：
```
calculator/
├── Calculator.h    // 头文件：声明类
├── Calculator.cpp  // 源文件：实现类的方法
└── main.cpp        // 主函数：测试程序
```

### 3.2 头文件 (Calculator.h)
头文件只写声明，不写具体实现。
```cpp
#pragma once
// 声明计算器类
class Calculator {
public:
    // 加法
    double add(double a, double b);
    // 减法
    double sub(double a, double b);
    // 乘法
    double mul(double a, double b);
    // 除法
    double div(double a, double b);
};
```
说明：这里只告诉编译器“有这些函数”，具体怎么算放在 .cpp 里。

### 3.3 源文件 (Calculator.cpp)
源文件实现头文件声明的功能，必须包含对应头文件。
```cpp
#include "Calculator.h"
#include <stdexcept> // 用于处理除数为0的异常

// 实现加法
double Calculator::add(double a, double b) {
    return a + b;
}

// 实现减法
double Calculator::sub(double a, double b) {
    return a - b;
}

// 实现乘法
double Calculator::mul(double a, double b) {
    return a * b;
}

// 实现除法
double Calculator::div(double a, double b) {
    if (b == 0) {
        throw std::invalid_argument("错误：除数不能为0！");
    }
    return a / b;
}
```

### 3.4 主函数文件 (main.cpp)
程序入口，调用其他模块的功能。
```cpp
#include <iostream>
#include "Calculator.h"

int main() {
    Calculator cal;

    double a = 10, b = 5;
    std::cout << "10 + 5 = " << cal.add(a, b) << std::endl;
    std::cout << "10 - 5 = " << cal.sub(a, b) << std::endl;
    std::cout << "10 * 5 = " << cal.mul(a, b) << std::endl;
    std::cout << "10 / 5 = " << cal.div(a, b) << std::endl;

    return 0;
}
```
